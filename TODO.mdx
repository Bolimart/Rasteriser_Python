Easy wins

X Gamma correction — apply image = image ** (1/2.2) before saving. Without it colours look washed out since monitors expect gamma-encoded output
Tiled rendering — split the image into tiles and render each independently, which makes parallelisation with multiprocessing trivial and would massively speed up your pure-Python rasteriser
Frustum culling — cull entire instances whose bounding box is outside the camera frustum before even transforming their triangles, rather than culling per-triangle

Lighting improvements

Multiple light types — you have point lights; adding directional lights (sun) and spot lights (cone) covers most real scenes. Directional lights have no position, just a direction, so light_dir is constant per light which is cheaper
Attenuation — point light intensity should fall off with distance: intensity / (1 + k * distance²). Without it distant objects are as bright as near ones
Emissive material channel — surfaces that glow independently of lighting, needed for light sources, screens, fire etc.

Post-processing

Tone mapping — maps HDR light values (which can exceed 1.0 when multiple lights add up) back to [0,1] without clipping. The simplest is Reinhard: c = c / (c + 1)
Ambient occlusion (SSAO) — darkens creases and corners by sampling the depth buffer around each pixel. Gives a lot of perceived depth for relatively little cost
Bloom — blurs and adds back pixels above a brightness threshold, making bright surfaces glow. Done in two passes: threshold + blur

Material improvements

Normal maps — store per-pixel normals in a texture and apply them in the shader, giving the illusion of surface detail without extra geometry. Requires the tangent and bitangent vectors you mentioned earlier
PBR materials — replace Blinn-Phong with a physically based model using roughness and metallic parameters instead of diffuse/specular/shininess. More parameters but more realistic and consistent under different lighting
Transparency sorting — you have the blend modes but transparent objects need to be rendered back-to-front (painter's algorithm) after all opaque geometry, otherwise blending composites against black

Pipeline infrastructure

Scene graph — a tree of transforms where child objects inherit their parent's transform, so you can group objects and move them together
Camera rotation — you have the TODO already; the missing piece is building a view matrix from the camera's u/v/normal basis vectors and applying it to world-space vertices before projection
LOD (level of detail) — swap high-poly models for low-poly versions at distance, based on the projected screen size of the bounding sphere
